🎥 챗GPT 대화 녹화기

  1. 이 파일을 크롬 또는 엣지로 열어요.
  2. 다른 탭에 챗GPT를 열어 두어요.
  3. 아래 녹화 시작을 누르고 챗GPT 탭을 골라요.
  4. 꼭 "탭 오디오도 공유"에 체크! (챗GPT 목소리 녹음)
  5. 다 끝나면 녹화 끝 → 영상 저장.
  6. 저장한 파일을 유튜브 스튜디오 → 만들기 → 동영상 업로드에 그대로 올리면 끝!
📱 휴대폰은 이 페이지로 녹화할 수 없어요. 휴대폰 기본 "화면 녹화"를 쓰세요!

갤럭시: 화면 위에서 두 번 쓸어내리기 → 화면 녹화 → 소리 설정 "미디어 소리 및 마이크" → 녹화 시작 → 챗GPT 열기

아이폰: 오른쪽 위에서 쓸어내리기 → ⏺ 녹화 버튼 꾹 누르기 → 마이크 켬 → 녹화 시작 → 챗GPT 열기
(녹화 버튼이 없으면: 설정 → 제어 센터 → 화면 기록 추가)

끝나면 영상이 갤러리/사진에 저장돼요 → 유튜브 앱 ＋ → 동영상으로 바로 업로드!
