# 『천천히, 온천』 — 책 원고 보관함

블로그·헬로톡에 올린 글을 모아 만드는 책입니다.
**지금은 1위~30위까지(1부·2부) 들어 있습니다.**

## 파일 설명

| 파일 | 무엇인지 |
|---|---|
| `원고_1-30위.md` | 책 본문 전체입니다. 이것이 원본입니다. |
| `만드는프로그램/` | 책에 들어가는 그림을 만드는 프로그램입니다. |

## 그림은 왜 여기 없나요?

그림 파일(.png)은 전부 합쳐 9MB가 넘습니다.
앱이 무거워지면 안 되니, **그림은 넣지 않고 만드는 프로그램만 넣었습니다.**
프로그램을 다시 돌리면 똑같은 그림이 다시 나옵니다.

```bash
python3 -m pip install Pillow qrcode
cd docs/책/만드는프로그램
python3 genimg.py     # 장 표지 29장
python3 genqr.py      # 지도 QR 코드
python3 genmap.py     # 지역 분포도
python3 gencover.py   # 책 표지 앞·뒤
```

## 책의 핵심 약속

**안 가본 곳은 안 가봤다고 씁니다.**

| 마크 | 뜻 |
|---|---|
| ✅ | 다녀온 곳 |
| 🏡 | 살았던 곳 |
| 🚃 | 근처까지 갔는데 못 들어간 곳 |
| 📖 | 아직 안 가본 곳 |

## 숫자에 대한 원칙

- 역 이름은 적습니다 (잘 안 바뀝니다)
- 걸리는 시간은 **"대략"** 으로만 적습니다
- **요금·시간표는 적지 않습니다** (자주 바뀌어서 틀리면 안 됩니다)
- QR은 **구글 지도 검색** 주소입니다. 공식 홈페이지 주소는 지어낼 수 없어 안 씁니다
- 예산은 숫자를 채워 넣는 **빈 표**로 넣었습니다 (부산 출발 기준)
- **효능(치료) 이야기는 쓰지 않습니다**
