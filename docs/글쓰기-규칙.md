# 글 쓸 때 지킬 것 (실수에서 배운 것)

이 앱의 주인은 일본 온천을 하루 한 곳씩 소개하는 시리즈를 블로그와 헬로톡에
올립니다. 글을 대신 써줄 때 아래를 지킵니다.

---

## 🚨 1. 가본 곳인지 먼저 확인할 것

글마다 제목 아래에 마크를 한 줄 넣습니다.

```
✅ 다녀온 곳 | 직접 가본 후기입니다
🏡 살았던 곳 | 1년 살았습니다
📖 아직 안 가본 곳 | 자료를 찾아 정리했습니다
```

**주인이 말해주기 전에는 가봤다고 쓰지 않습니다.** 모르면 📖 로 두고 물어봅니다.

### 실제로 있었던 실수 ①

게로 온천 글을 "신기했습니다", "참 좋았습니다" 처럼 다녀온 것처럼 썼습니다.
주인은 그곳에 간 적이 없었습니다. 거짓 후기가 될 뻔했습니다.

### 실제로 있었던 실수 ②

노보리베츠는 **다녀온 곳**인데, 헬로톡 글에 이렇게 썼습니다.

- "숙소는 어디가 좋았나요?"
- "모래찜질, 실제로 어떤 느낌인가요?"

가본 사람이 남에게 "어떤가요?" 라고 물으면 앞뒤가 맞지 않습니다.
읽는 사람은 금방 알아챕니다.

---

## ✍️ 2. 마크에 따라 문체와 질문이 달라집니다

| | 📖 안 가본 곳 | ✅ 다녀온 곳 |
|---|---|---|
| 서술 | ~라고 합니다 / ~라네요 | ~했습니다 / ~더라고요 |
| 질문 | **"가보신 분, 어떤가요?"** | **"저는 ○○였는데 여러분은?"** |
| 위치 | 정보를 모으는 사람 | 경험을 나누는 사람 |

✅ 글에서도 질문은 넣습니다. 다만 **묻는 질문이 아니라 나누는 질문**입니다.

- ❌ "천연 족욕 해보신 분, 어땠나요?"
- ✅ "저는 천연 족욕이 제일 좋았는데, 여러분의 베스트는 어디였나요?"

가본 사람이 물어도 자연스러운 것들:
- 자기가 못 본 계절, 못 본 공연
- 다음에 갈 때를 위한 추천
- 남들의 다른 선택 ("저는 A였는데 B는 어떠셨어요?")

---

## 🔢 3. 모르는 사실은 비워둘 것

가격, 운영시간, 입장료, 본인의 감상은 **지어내지 않습니다.**
주인이 채우도록 빈칸으로 두고, 어디를 채워야 하는지 알려줍니다.

빈칸은 되도록 **한두 곳**으로 줄입니다. 주인은 빈칸이 많으면 부담스러워합니다.

|---|---|
| 네이버 블로그 | 길어도 됩니다. 줄바꿈을 넉넉히 |
| 헬로톡 | **2000자 이내** (앱이 자동으로 나눠주긴 합니다) |

## 🖼️ 5. 사진은 본인 것이 가장 좋습니다

다녀온 곳이면 사진이 있을 가능성이 높으니 **먼저 물어봅니다.**
없을 때만 AI 그림 주문 문장을 만들어 드립니다.
AI 그림을 쓸 때는 글 맨 아래에 이 한 줄을 넣습니다.

```
※ 이미지는 AI로 만든 일러스트입니다
```

## 🗣️ 6. 말투

- 쉬운 한국어 존댓말. 초등학생도 알아들을 수 있게
- 전문용어를 쓰면 괄호로 풀어줍니다
- 주인의 목소리로 씁니다. 자료를 옮겨 적은 느낌이 나지 않게

## 🚫 7. 📖(안 가본 곳) 글에서 쓰면 안 되는 말투

글머리에 📖 를 달아놓고도, 본문에서 **가본 사람처럼 말하는 실수**가
실제로 두 번 있었습니다. 마크만 바꾸면 되는 게 아니라 **문장도 바꿔야 합니다.**

### 실제 사례 (14편 야마시로, 📖)

```
❌ 차 안 타도 됩니다.
   저는 이게 제일 좋아요.
```

"저는 이게 제일 좋아요" 는 **가서 겪어본 사람의 말**입니다.
안 가본 곳에서는 쓸 수 없습니다.

```
✅ 차 안 타도 된다고 합니다.
   저는 이런 곳을 좋아해서, 여기가 많이 끌려요.
```

### 바꿔 쓰는 표

| 안 가본 곳에서 ❌ | 이렇게 ✅ |
|---|---|
| ~였어요 / ~했어요 | ~라고 합니다 / ~라고 해요 |
| 저는 이게 제일 좋아요 | 저는 이런 걸 좋아해서 끌려요 |
| 물이 참 좋았어요 | 물이 좋다고 소문났어요 |
| 추천합니다 | 가보고 싶습니다 |
| (단정) 보입니다 | 보인다고 합니다 |

### 점검 방법

글을 다 쓴 뒤, **📖 글이면 과거형 문장을 전부 찾아봅니다.**
"~했어요 / ~였어요 / ~봤어요" 가 남아 있으면 거의 틀린 문장입니다.

반대로 ✅·🏡 글에서는 **남에게 "어떤가요?" 라고 묻지 않습니다.**
(이것도 실제로 있었던 실수입니다. 2번 항목 참고)

## 🚃 8. 마크가 하나 늘었습니다

| 마크 | 뜻 |
|---|---|
| ✅ | 다녀온 곳 |
| 🏡 | 살았던 곳 |
| **🚃** | **근처까지 갔는데 못 들어간 곳** |
| 📖 | 아직 안 가본 곳 |
| ❓ | 아직 안 물어봄 |

### 🚃 는 이런 경우입니다

18편 이카호가 그랬습니다.
주인은 이카호에 가려고 **군마까지 갔지만**,
헬로톡 친구를 만나느라 **온천에는 못 갔습니다.**

이런 건 ✅ 도 아니고 📖 도 아닙니다.

그리고 이 이야기 자체가 **좋은 글감**이었습니다.
"거기까지 갔는데 못 갔다"는 건 지어낼 수 없는 이야기니까요.

### 🚃 글을 쓸 때

- 간 데까지는 **겪은 일로** 씁니다 (군마까지 간 것, 친구를 만난 것)
- 못 간 온천은 **📖 와 똑같이** `~라고 합니다` 로 씁니다
- 끝에 "다음에는 꼭 가보겠습니다" 로 맺으면 자연스럽습니다

### 비슷한 경우

23편 뉴토는 숙소 일곱 곳 중 **한 곳만** 다녀오셨습니다.
이럴 때는 간 곳은 ✅, 나머지는 📖 로 나눠서 적습니다.

## 📏 9. 헬로톡 글은 글자수를 꼭 세어서 쓴다

헬로톡은 한 번에 **2000자**까지만 올라갑니다.
그런데 눈대중으로 맞추다가 실제로 **2057자**를 드린 적이 있습니다.
(24편-2 곤피라) 주인이 올리려다 막혔을 수 있는 실수였습니다.

**그래서 이제 매 편마다 글자수를 세어서 숫자로 알려드립니다.**

| 기준 | 글자수 | 할 일 |
|---|---|---|
| 안전 | 1800자 이하 | 그대로 |
| 괜찮음 | 1800 ~ 1950자 | 그대로 |
| 위험 | 1950자 넘음 | 줄인다 |

### 줄일 때는 영어부터

세어보니 길이가 이렇게 나옵니다.

- 한국어 약 550자
- 일본어 약 500자
- **영어 약 950자** ← 가장 깁니다

영어는 글자 하나하나가 짧아서 줄이 많아지고,
그만큼 글자수를 많이 먹습니다.

그러니 **줄일 때는 영어를 먼저** 줄입니다.
한국어·일본어는 주인이 직접 읽는 부분이라 되도록 그대로 둡니다.

### 영어 줄이는 방법

- 짧은 줄 두 개를 한 줄로 붙입니다
- 한국어·일본어에 있는 설명 중 하나는 생략해도 됩니다
- 뜻은 남기고 꾸밈말만 뺍니다

### 세는 방법 (내가 쓰는 명령)

```bash
python3 -c "import io,sys; s=io.open(sys.argv[1],encoding='utf-8').read().rstrip(); print(len(s))" 글.txt
```

## 💰 10. 「가는 길」은 돈을 생각해서 쓴다

주인이 말씀하셨습니다. **"가는 방법은 가격을 생각하고 글 쓰기"**

### 그런데 요금 숫자는 쓰지 않습니다

항공권은 같은 노선도 **날마다 두세 배** 차이 납니다.
숫자를 적으면 한 달 뒤에 틀린 글이 됩니다.
한 군데가 틀리면 앞의 쉰 편까지 못 믿게 됩니다.

```
❌ 항공권 12만 원, 버스 1,800엔, 신칸센 8,000엔
✅ 직항이라 이게 제일 쌉니다 / 신칸센 값이 붙습니다
```

### 대신 「싼 길 / 빠른 길」 두 가지로 적습니다

```
🛫 부산에서 가는 길

💰 돈을 아끼는 길
   (직항 쪽, 갈아타기 적은 쪽)

⚡ 시간을 아끼는 길
   (신칸센·경유 쪽)

저라면 ○○ 쪽입니다. 왜냐하면 ...

※ 항공권은 철과 예약 시기에 따라
  많이 다릅니다. 직접 확인해 주세요.
```

### 돈 이야기를 숫자 없이 하는 방법

- **직항이 있으면 거의 항상 싼 길**입니다
- **갈아타기가 한 번 늘면** 비행기값 한 번 더 + 반나절
- **신칸센은 멀수록 비쌉니다.** 가까우면 기차, 멀면 비행기
- **고속버스는 싸지만 오래** 걸립니다
- **한 번 가서 여러 곳을 보면 그만큼 싸집니다**
  → 가까운 편끼리 묶어주면 그게 제일 큰 절약입니다
  (예: 마쓰야마로 들어가 3편 도고 + 53편 이야)
- 여러 곳을 돌 때만 **JR 패스**를 따져볼 만합니다

### 부산 직항 (확인된 것)

| 가는 곳 | 쓸 수 있는 편 |
|---|---|
| **후쿠오카** | 규슈 전부 (4·8·10·12·21·44편) |
| **마쓰야마** | 시코쿠 (3·24②·53편) — 주인 확인 2026-11 |
| **삿포로** | 홋카이도 (5·46①·46②·48편) |
| 오사카 | 간사이·주고쿠·시코쿠 동쪽 |
| 도쿄 | 간토·도호쿠·이즈·나가노 |

**이 표가 글의 결론을 만듭니다.** 주인이 어디를 다녀왔는지는
'거리'가 아니라 '직항이 있느냐'로 설명됩니다.
새 직항을 알게 되면 여기에 바로 적을 것.
