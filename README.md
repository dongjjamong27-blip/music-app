# 자동 출석체크 (안드로이드 앱)

휴대폰에서 **정해진 시간에 앱을 자동으로 열고, 출석체크 버튼을 자동으로 눌러 주는** 앱입니다.
PC 없이 휴대폰 하나만 있으면 됩니다.

> 📖 **처음 쓰시나요? → [설치방법.md](설치방법.md) 를 보세요.**
> 다운로드부터 권한 설정까지 하나하나 그림처럼 자세히 적어 뒀습니다.

---

## 1. 어떻게 동작하나요?

```
정해진 시간 도착
      ↓
휴대폰 화면 켜기
      ↓
등록한 앱 열기  (예: 캐시워크)
      ↓
화면에서 "출석체크" 글자 찾기
      ↓
찾으면 자동으로 누르기 (클릭!)
      ↓
팝업 뜨면 "확인 / 닫기" 도 자동으로 누르기
      ↓
다음 앱으로 이동 → 전부 끝나면 홈 화면으로
```

안드로이드에서는 **접근성 서비스**만 화면 글자를 읽고 버튼을 대신 누를 수 있어서,
이 앱은 접근성 서비스를 사용합니다. (권한을 켜 줘야 동작합니다)

## 3. 앱 사용법 (순서대로 따라하기)

### 1단계 — 접근성 권한 켜기
앱을 열고 **`설정 열기`** → 목록에서 **`자동 출석체크 도우미`** → **켜기**.
✅ 표시가 뜨면 성공입니다.

### 2단계 — 출석체크 할 앱 등록
오른쪽 아래 **`+ 앱 추가`** 버튼 →
1. 휴대폰에 설치된 앱 목록이 나옵니다. 원하는 앱을 고르세요.
2. **그 앱 화면에 실제로 보이는 버튼 글자**를 적습니다.
   - 예: `출석체크`
   - 여러 개면 쉼표로: `출석체크, 출석, 오늘출석`

> 💡 **중요:** 글자는 그 앱을 직접 열어서 눈으로 본 그대로 적어야 합니다.
> (띄어쓰기는 크게 상관없지만, 글자가 다르면 못 찾습니다)

**`적은 순서대로 하나씩 누르기`** 체크박스:
- **체크 안 함** → 적은 글자 중 화면에 보이는 것 **하나만** 누름 (보통 이걸로 충분)
- **체크 함** → 적은 **순서대로 전부** 누름
  - 예: `출석체크, 확인, 닫기` → 출석체크 누르고 → 확인 누르고 → 닫기 누름
  - 출석 버튼이 여러 단계인 앱에 사용하세요.

### 3단계 — 시간 정하고 자동 실행 켜기
`시간 바꾸기` 로 매일 실행할 시간을 정하고, **자동 실행 스위치를 켜세요.**

### 4단계 — 배터리 절약에서 제외 (꼭 하세요)
`배터리 설정 열기` → 이 앱을 **제한 없음 / 최적화 안 함** 으로 바꾸세요.
이걸 안 하면 폰이 절전 중일 때 자동 실행이 안 될 수 있습니다.

### 마지막 — 테스트
**`지금 바로 한 번 실행해 보기`** 를 누르고 폰을 만지지 말고 지켜보세요.
아래 **실행 기록**에 ✅ 또는 ❌ 와 이유가 남습니다.

## 4. 잘 안 될 때

| 증상 | 해결 방법 |
|---|---|
| ❌ "글자를 못 찾았어요" | 그 앱을 직접 열어서 버튼 글자를 눈으로 확인하고 똑같이 다시 적으세요 |
| 앱은 열리는데 안 눌림 | `버튼 찾는 시간(초)` 을 30~60초로 늘려 보세요 (앱이 느리게 켜지는 경우) |
| 광고가 먼저 떠서 실패 | `순서대로 누르기` 를 켜고 `닫기, 출석체크` 처럼 광고 닫기를 먼저 적으세요 |
| 정해진 시간에 안 됨 | 배터리 최적화 제외 + 접근성 권한이 꺼지지 않았는지 확인 |
| 잠금화면에서 안 됨 | 비밀번호/지문 잠금은 앱이 풀 수 없습니다. 폰이 켜져 있는 시간으로 설정하세요 |

## 5. 소스 구조 (개발용)

| 파일 | 하는 일 |
|---|---|
| `MainActivity.kt` | 설정 화면 (앱 추가, 시간 설정, 기록 보기) |
| `AttendanceAccessibilityService.kt` | 화면 글자를 읽고 **실제로 클릭하는** 부분 |
| `AutoCheckService.kt` | 앱 열기 → 버튼 찾기 → 누르기 순서를 진행 |
| `AlarmScheduler.kt` | 매일 정해진 시간에 깨우는 알람 |
| `Store.kt` | 설정과 실행 기록 저장 |
| `Updater.kt` | 앱 안에서 새 버전 받아 설치 |
| `WakeActivity.kt` | 꺼진 화면 켜기 |

## 6. 주의

- 본인 휴대폰에서 **본인 계정의 출석체크**를 편하게 하기 위한 개인용 도구입니다.
- 인터넷은 `업데이트 확인` 을 눌렀을 때 새 버전을 받는 용도로만 씁니다. 어떤 정보도 밖으로 보내지 않습니다.
- 앱마다 자동화 사용을 약관으로 금지할 수 있으니, 사용 전에 해당 앱의 이용약관을 확인하세요.
